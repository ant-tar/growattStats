# Archived frontend comparison prototypes

These experimental renderers preceded the selection of ECharts for beta12.
They are reference source, not package elements. Original component-relative paths
are retained. ECharts itself is now in the production assets.

The production growattShowChart snippet and dashboard use the shared ECharts renderer.
Comparison snippets, additional libraries and CSS are excluded from the transport.
Historical local resources can still reference previously installed experimental files;
they are not supported production entry points.

No Highstock distribution is included here. The earlier four-chart comparison requires
its own applicable Highcharts license and is not part of this component release.
