## Название

growattStats

## Краткая подпись

Статистика солнечной выработки Growatt и графики истории для MODX 2.

## Краткое описание

Показания солнечной электростанции через Growatt API: выработка за сегодня,
общая выработка, интерактивный график истории и виджет панели управления MODX.
Английский и русский интерфейс, автоматическое обновление через CronManager.
Для MODX 2.8.x.

## Полное описание

growattStats подключает сайт на MODX 2 к Growatt API. Компонент показывает
выработку за сегодня и за всё время в отдельных карточках, строит график
накопленной истории с выбором периода и навигатором и выводит статистику
станции в панели управления MODX.

При установке запрашиваются токен Growatt API и Plant ID. Токен отображается
в системных настройках как поле пароля. Название станции задаётся отдельно,
а оформление можно изменить с помощью собственных чанков. Интерфейс,
настройки, установщик и подписи графика переведены на английский и русский.

Для автоматического обновления требуется CronManager. Установщик создаёт
активное задание с интервалом 15 минут. Внешний планировщик должен запускать
CronManager каждую минуту; запрос к Growatt выполняется по расписанию задания.
Интервал можно изменить в CronManager, например на 60 минут.
Обновление компонента сохраняет существующее расписание, данные доступа и историю.

История накапливается при успешных обращениях к API. Она хранится локально
как публичные данные графика: одна точка за день, обновляемая последующими
запросами. При ошибке API остаются предыдущие показания. Пропущенные даты
автоматически не восстанавливаются.

Это бета-версия для MODX Revolution 2.8.x. Компонент является независимой
интеграцией сообщества и не является официальным продуктом Growatt.

## Требования

- MODX Revolution 2.8.x; MODX 3 пока не поддерживается.
- PHP 7.4+ с cURL и JSON, включая PHP CLI планировщика.
- CronManager 1.2.2+.
- Рабочие Growatt API token и Plant ID.
- Внешний планировщик, доступ к базе данных и права записи в кеш MODX и каталог данных компонента.

Фактически проверено: MODX **2.8.8**, PHP **8.1.34**, CronManager **1.5.1**, MySQL.
Название локального каталога `MODX-2.8.6` не означает, что тестировалась версия 2.8.6.

## Установка

1. Установите CronManager.
2. Загрузите транспортный пакет growattStats через установщик MODX.
3. Введите `growattstats_token` и `growattstats_plant_id`.
4. В системных настройках пространства имён `growattstats` задайте
   `growattstats_plant_name` — название станции.
5. Добавьте на страницу `[[!growattShowChart]]` и подключите виджет growattStats к нужному дашборду.
6. Настройте внешний запуск CronManager и проверьте успешное выполнение в журнале заданий.

Для отдельного графика можно переопределить название:

```modx
[[!growattShowChart? &plantName=`Моя солнечная станция`]]
```

Для своего оформления скопируйте чанк `growattShowChart` под другим именем:

```modx
[[!growattShowChart? &tpl=`MySolarChart`]]
```

Пакет обновляет штатные чанки. При обновлении пустые поля данных доступа
сохраняют прежние значения. Тип пароля скрывает ввод в редакторе настройки,
но не шифрует значение в базе данных.

## Запуск cron

Служба cron должна работать: одной записи в crontab недостаточно.
На Debian/Ubuntu с systemd администратор может выполнить:

```sh
sudo apt-get install cron
sudo systemctl enable --now cron
systemctl is-active cron
```

От пользователя сайта откройте `crontab -e` и добавьте строку с путями своего сервера:

```cron
* * * * * /usr/bin/php /path/to/modx/assets/components/cronmanager/cron.php
```

Проверьте запись командой `crontab -l`. В пользовательском crontab колонка
имени пользователя не нужна. Для систем семейства RHEL используются пакет
`cronie` и служба `crond`. На обычном хостинге настройте Cron Jobs в панели
или обратитесь в поддержку хостинга. На Windows используйте Планировщик заданий
с минутным интервалом; пример для Laragon есть в README.

- [Настройка CronManager](https://jako.github.io/CronManager/usage/)
- [Документация crontab](https://man7.org/linux/man-pages/man5/crontab.5.html)
- [Руководство Ubuntu](https://help.ubuntu.com/community/CronHowto)
